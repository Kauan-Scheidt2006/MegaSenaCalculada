# Especificações dos agentes

Cada arquivo desta pasta é um contrato de papel reutilizável. Ele deve ser consultado somente quando o papel for selecionado; não é uma configuração carregada automaticamente pelo Codex.

Toda especificação declara missão, acionamento, entradas mínimas, responsabilidades, limites, entrega e handoff. O coordenador deve incluir na delegação o objetivo concreto, o escopo, os arquivos sob propriedade temporária, as restrições e o formato da entrega. O nome do papel sozinho não é uma tarefa suficiente.

Crie um novo papel somente quando houver responsabilidade estável que não caiba nos existentes. Um workflow repetível deve ser uma skill; uma regra global e curta deve ficar no `AGENTS.md`; uma escolha duradoura deve ser registrada em `docs/decisoes/`.
